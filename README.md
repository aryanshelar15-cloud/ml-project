# Machine Learning Projects

A collection of beginner-to-intermediate Machine Learning projects developed using Python and Scikit-learn.

## Projects

### 1. Customer Churn Prediction

**Type:** Classification
**Algorithm:** Random Forest

Predicts whether a customer is likely to churn and identifies high-risk customers for targeted retention strategies.

**Key Features:**

* Data preprocessing
* Categorical encoding
* Train-test split
* Random Forest classification
* Churn probability prediction
* Customer risk categorization
* Retention recommendations

---

### 2. House Price Prediction

**Type:** Regression
**Algorithm:** Multiple Linear Regression

Predicts house prices based on features such as area, bedrooms, location score, and house age.

**Key Features:**

* Feature selection
* Linear Regression
* Price prediction
* RMSE evaluation
* R² score evaluation

---

### 3. Customer Segmentation

**Type:** Unsupervised Learning
**Algorithm:** K-Means Clustering

Segments customers into different groups based on income, spending behavior, visits, and purchase value.

**Key Features:**

* Feature scaling
* K-Means clustering
* Four customer segments
* Cluster profiling
* Marketing campaign recommendations
